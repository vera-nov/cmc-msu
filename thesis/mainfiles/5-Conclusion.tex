
\section{Заключение}

В рамках выпускной квалификационной работы:

\begin{itemize}
    \item Сформирован экспериментальный набор данных для оценки качества русскоязычных радиологических отчётов.
    \item Разработаны метод оценки русскоязычных радиологических отчётов с использованием текстовых и мультимодальных нейросетевых моделей и методика адаптивного отбора и настройки его компонент.
    \item Показана согласованность предложенного метода с врачебными оценками.
\end{itemize}

Алгоритмы, реализующие разработанные метод и методику его настройки, написаны на языке Python 3.
